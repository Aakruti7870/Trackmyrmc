# RMC Discovery API Quick Reference

All `/api/super-admin/rmc-discovery/*` endpoints require the existing `authority` role.

The only customer-safe listing is `GET /api/public/rmc-plants`, which applies the strict approved + published + active + order-capable filter.

See [`RMC_PLANT_DISCOVERY.md`](RMC_PLANT_DISCOVERY.md) for complete contracts and deployment guidance.
