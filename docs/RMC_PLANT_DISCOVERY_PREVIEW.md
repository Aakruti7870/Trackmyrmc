# RMC Plant Network UI Preview

The implemented Super Admin route is `/rmc-plant-network` and contains these separate views:

- Dashboard metric cards
- Discover Plants scope selector for Market, District and Maharashtra
- Active import progress with query/results/new/duplicate/error counters
- Review Queue with confidence reasons, Google Maps link, Approve as Draft, Reject and Mark Duplicate
- Onboarding list with status badges and onboarding approval action
- Active Plants and Inactive Plants lists
- Import History
- Market Coverage

The visual implementation uses the existing TrackMyRMC cards, theme tokens, typography, buttons, responsive grids and mobile scrolling. Runtime screenshots require a deployed preview connected to a migrated test database and are intentionally not fabricated from mock data.
